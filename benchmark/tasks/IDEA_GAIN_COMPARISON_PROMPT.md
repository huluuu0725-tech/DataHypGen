# Idea 相对原论文增益比较 · 分析提示词（真实代码验证维度通用模板）

> 用途：对基准中每篇"真实代码验证"论文，在其 idea 生成与源码验证完成后，用本提示词驱动
> "新 idea vs 原论文"的增益比较分析。占位符用 `{}` 标出；文末附本案例（postfire_debris_flow_initiation）
> 的实例填入值。

---

## 输入

- 原论文全文：`{PAPER_FULLTEXT_PATH}`
- 原论文数据/代码快照：`{PAPER_ASSET_DIR}`
- 原论文 DOI：`{PAPER_DOI}`
- 任务输入（数据集基本特征描述）：`{TASK_PROMPT_PATH}` 下的 `prompt.json`
- 新产生 idea：`{IDEAS_JSON_PATH}`（终版主张 + 预登记 observable / mechanism_relevant_contrast /
  falsification_condition）与 `{TRAJ_DIR}`（成熟化轨迹、探针与终检记录、评审分）
- 基线与验证工作区：`{VALIDATION_DIR}`（协议复现脚本、历轮验证结果 JSON）

## 你要回答的唯一问题

**新 idea 相较原论文的原配置，能观察到什么原配置观察不到的新信息，或带来多大的真实增益？**
不是"把原论文的表格再跑一遍"，而是设计一个能真正分辨增量的比较。

## 比较设计规则（按序执行）

1. **先冻结原配置**：把原论文的过滤规则、特征构造、模型超参、折协议、阈值、指标逐位复现
   （复现验收：过滤行数、披露系数、指标误差三条都要对上），作为基线。idea 永远以
   "基线上的最小增量"实现——禁止混入任何其他改动，否则 Δ 无法归因。

2. **先分类，再选指标**——把 idea 的产出归入三类，分别用不同判定标准：
   - **a. 性能增益**：以原论文指标为锚（同表、同折、同阈值，逐折配对 Δ），且必须双协议
     （事件随机折 + 按火/按流域分组折）缺一不可。允许增加原论文没有的指标，但原论文指标
     至少保留作锚点。
   - **b. 效应估计**（方向/显著性）：无"高低好坏"。判定 = 按 idea 自己预登记的控制集控制
     混杂后，方向是否仍被数据支持。**原始显著不算数**——控制后消失即证伪，即使方向仍对。
   - **c. 新信息/新结论**：最有价值的类别，允许**完全自定义比较维度**——原论文没测的变量、
     被弃用的数据、协议本身的偏差、适用窗口外的行为、采样结构。但每条自定义比较必须同时给出：
     (i) 与原配置的锚点关系——原配置在这个维度上是盲的还是错的；
     (ii) 预登记证伪条件；
     (iii) 数据边界声明（结论在哪个窗口/哪张表内成立）。

3. **允许不采纳原论文指标的情形（必须显式声明）**：当 idea 的研究问题落在原论文指标覆盖
   之外（时间轴外推、被弃用变量、采样结构、协议偏差、家族数据口径）时，可自定义指标，
   但自定义指标必须能回答："原配置如果看这个维度，会看到什么、看不到什么"。

4. **预登记先行**：跑任何数之前，写下每个比较的证伪条件（优先取自 idea 自己的
   falsification_condition 字段）；跑完后按条件判定，禁止事后挑选有利口径。

5. **混杂控制**：任何"原始显著"的效应，必须按 idea 声称的机制补控制变量重测；
   控制后消失 = 证伪。

6. **方向与文本一致**：结论中的方向性断言必须与统计量逐字一致；方向核以统计句为准，
   禁止主语互换式换皮（"高→低"与"低→高"是同一命题的两种写法，不构成修复）。

7. **边界诚实**：原数据表的结构性边界（时间窗、空间分辨率、哨兵值、单表限制）必须写进结论；
   外推到窗口外需家族数据并单独标注；禁止跨表移植数值结论。

## 禁止事项

- 禁止把不同基线、不同表的 Δ 数值横向比较（每行 Δ 必须标注其基线）；
- 禁止用单协议（事件随机折）的增益下结论；
- 禁止把效应估计/描述统计读成"高好低坏"的性能分；
- 禁止把历史轮次的实测结论移植到新 idea（每轮新测）；
- 禁止在没有任何统计的情况下输出方向性断言。

## 输出格式（三张表）

**表 A · 增益总表**
`idea / 创新维度 / 相对原配置的机制增量 / 验证判定（成立/证伪/带警示成立）/ 关键数字`

**表 B · Δ指标表**
`知识来源 / 基线（注明是原配置还是弱基线）/ Δ指标（P1 事件随机 | P2 分组）/ 折提升占比 / 备注`

**表 C · 新信息清单**
`原配置在该维度看到什么、看不到什么 / 本比较用什么维度暴露了它 / 判定 / 对原论文结论的修正含义`
